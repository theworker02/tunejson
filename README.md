# tunejson

Tune numeric json values, ranges, and human-readable units.

**Site:** https://theworker02.github.io/tunejson/

## Install / run

```bash
git clone https://github.com/theworker02/tunejson.git
cd tunejson
node src/cli.js
node --test
```
